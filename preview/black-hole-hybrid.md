# 黑洞混合渲染样张（预览专用）

静态单帧、固定视角、冻结时间。只用于验证视觉方向，**未接入正式主题**。

- 预览页：`preview/black-hole-hybrid.html`
- 渲染器：`preview/black-hole-hybrid.js`
- 截图：`black-hole-hybrid-1600x900.png`（全帧）、`black-hole-hybrid-crop.png`（中心 600×600）、`black-hole-hybrid-500w.png`（缩放 500px 宽）

打开方式：浏览器直接打开 `black-hole-hybrid.html`。页面无交互、无文字、无设置面板。

## 复用的现有计算

全部来自 `src/runtime/black-hole.js`，本样张未修改该文件：

| 复用项 | 用途 |
| --- | --- |
| `UniverseBlackHole.trace(u, v, angle)` | 弯曲光线积分、黑洞捕获判定、吸积盘穿行半径/方位角、多普勒增益、光子环权重 |
| `UniverseBlackHole.shade(ray, time, brightness)` | 盘面通量模型（内缘权重、臂状纹理、径向条带、边缘淡出） |

没有重写测地线方程，也没有迁移 WebGL。

## 取景比例与源码的差异（重要）

`src/runtime/black-hole.js` 内部用 `SHADOW_SHARE = 0.44` 推导视场张角 `TAN_HALF`，该常量不对外导出。本预览要更紧的取景，改用本地 `SHADOW_SHARE = 0.40`。

后果：`trace()` 仍按源码的 0.44 采样，而本模块的暗影与光子环按 0.40 反向求解屏幕位置，两者投影比例相差 **1.10 倍**。视觉上盘的内缘仍贴在环外侧（盘内缘投影约 187 px，环半径约 180 px），没有可见错位；但这不是同一套投影，**不要据此认为环与盘在数学上严格对齐**。若要严格一致，需要源码导出 `TAN_HALF`，本次不改源码。


## 艺术增强（非物理，预览专用）

1. **临界曲线解析求解**：沿屏幕方位角二分 `impact = B_CRIT`，得到正圆路径，暗影填充与光子环共用同一路径，取代原实现的 `|-/\` 符号描边；但该路径用的是本模块取景比例，与 `trace()` 的采样比例相差 1.10 倍，见上节。
2. **径向发射曲线**：`smooth(6.05, 6.6, r) * (1 - smooth(10.5, 14, r))`，压住外缘，让环面不糊成实心甜甜圈。
3. **多普勒阻尼**：`boost = 1 + (boost - 1) * 0.4`，避免单侧爆成白块。
4. **色调软肩**：`value / (1 + value * 1.5)`，保留高光层次，字符不被冲成纯白。
5. **左右不对称**：`1 + 0.09 * (1 - 2 * x/cols)`，左侧略亮。
6. **网格平滑**：两遍 3×3 盒式模糊，消掉单格噪点，让亮带与弧线连续。
7. **曝光归一化**：按最亮格归一，让字符梯度用满整个字阶，避免整片同字符。
8. **柔光**：盘面烘焙成低分辨率发光层，两次模糊叠加（紧 + 宽），不淹没字符。
9. **调色**：12 级暖琥珀调色板 `#22130a → #ffe3b8`。

以上均为观感取舍，**不承诺科学精确**。

## 实体检查结果（1600×900，Chromium 无头截图）

- **暗影圆度**：页面内复算 `impactAt`，12 个方位角的临界半径恒为 0.4015（与 `SHADOW_SHARE = 0.40` 一致），路径为正圆；截图实测环线在 90°/270° 方向半径 180/181 px（0.4015 × 450 ≈ 180.7）。
- **遮挡正确**：暗影内 0.8R 范围内检出 4048 个琥珀字符像素，分布于 40 行 —— 前景盘确实横过黑影，最后没有被黑圆覆盖。
- **完整不裁切**：亮区包围盒 (335,101)–(1264,761)，左/右/上/下留白 335/335/101/138，全部落在画面内。
- **缩小可辨**：320/500/800 px 宽缩放下，暗影核心亮度约 15、吸积带约 53，对比约 3.5×，主轮廓稳定。
- **无文字标签**：页面 DOM 无可见文本（仅有 `<title>`）。

## 已知局限

- 只验证独立样张，**不宣称已解决正式聊天界面的遮挡问题**；正式界面的遮挡仍取决于正式渲染器的绘制顺序，本预览不能替代。
- 环面内外缘为预览曲线，非物理盘模型。
- 暗影/环与 ASCII 盘不是同一套投影比例（差 1.10 倍），见「取景比例与源码的差异」。
- 独立 review 记录的未修项：`dispose()` 未复位 `ctx.filter`、未取消已排队的模糊合成帧；`window.blackHoleHybrid` 未置空。均不影响单帧静态截图。
- 本文件的实测数值来自 Chromium 无头截图与页内 `Runtime.evaluate`，无法仅凭仓库内文件复核。
