# 选中态改动史（第四十八轮 → 第五十七轮）

这份表只记一件事：**选中态**被改过什么、哪些被否、为什么。目的是避免同一套方案被反复提出。

悬停态、黑洞、壁纸、玻璃、悬停透镜、宇标、置顶、吸积流不在本表范围。

---

## 一、现行规则（第五十七轮，2026-10-31）

### 会话行选中 = 引力放大

作用对象：`.wnFoaW_title`，即行内第二个 `span`（第一个是图标槽）。

| 属性 | 值 | 说明 |
|---|---|---|
| `font-size` | `1.08em`（14px → 15.12px） | 只放大标题，时间戳与 32px 行高不动 |
| `letter-spacing` | `0.02em`（0.3024px） | 轮廓被撑开，不是单纯加粗 |
| `text-shadow` | `0.45px 0.45px 0 currentColor` | 单层、单向偏移像；对称双影会被读作「文字加重」 |
| `transition` | `200ms ease-out`，三属性同时 | 字号过渡会逐帧重排该行 |
| 底色 | 无 | 显式把 `--dsw-alias-interactive-bg-hover` 压回 `transparent` |

`prefers-reduced-motion`（`data-uni-motion='reduced'`）：只关过渡，终态照样放大。

选中行不参与悬停收束（`EXCLUDED` 里已排除 `[aria-selected='true']`），避免放大与 0.97 两套变换打架。

### 其他对象选中 = 无效果

除会话行之外，任何选中对象都不带主题自加的视觉变化。底色、边框、下划线一律归宿主官方。

## 二、已否决方案（不要再提）

| 方案 | 轮次 | 否决原因 |
|---|---|---|
| 六层对称 `text-shadow` 重影 | 第四十八轮 | 是重影不是形变，被读作「文字加重」 |
| 左右双向光谱分离（左青右红） | 第四十八轮 | 规格要求单侧、有明确方向，不要四周均匀 |
| SVG 位移图 + `feDisplacementMap` 真形变 | 第五十至五十二轮 | 「根本没法看」；13px 字上径向位移场近似常数，只是整体平移 |
| `::after` 放大版外侧像 | 第五十至五十二轮 | 同上，一起被撤 |
| WAAPI 两阶段入场（峰值 → 稳定） | 第五十至五十二轮 | 同上，一起被撤 |
| 放大 1.07 + 滚动闸 | 第五十三轮 | 落地前叫停 |
| 整体放大整个列表项 | 第五十三轮 | 会推动布局与邻居 |
| 网格/噪声位移（`feTurbulence`） | — | 随机噪声在文字边缘读作毛刺，规格明确禁止 |

## 三、时间线

- **第四十八轮**：多普勒红移（对称双向、青红分离）+ 引力透镜（六层对称重影）+ 底色/边框/下划线压制。
- **第五十至五十二轮**：改成 SVG 位移图 + `::after` 外侧像 + WAAPI 入场。用户判「根本没法看」，全撤。
- **第五十三轮**：改成放大 1.07 + 滚动闸（`data-uni-sel-steady`）。落地前叫停，全部删除。
- **第五十四轮**：只留会话行，其他选中态无效果。
- **第五十五轮**：把底色、边框、下划线还给官方；删掉七类钩子的压制块与标签页 `::after` 压制。
- **第五十六轮**：删掉多普勒红移与整套入场变量；`selection.js` 只剩注释，effect 计数回到 9。
- **第五十七轮**：会话行选中改「引力放大」，去掉会话行底色。
- **第五十八轮**（现行）：把引力放大推广到全部八类选中钩子，撤销所有选中底色。用户 m02209：「修，并且把这些跟那七类一起调整为会话选定状态的放大效果。不要背景和边框。」

## 四、仍然有效的既有事实

- 官方一条规则同时覆盖悬停与选中：
  `.sessionRow:hover, .sessionRow.selected { background: var(--dsw-alias-interactive-bg-hover) }`
- 该令牌暗 `#87cbd51a`（brand-primary 10.2%）、亮 `#00687417`（9%）。
- 本表把该令牌压成 `transparent`，让悬停只剩收束；第五十五至五十六轮曾在七类选中钩子上还原，第五十七轮撤掉会话行那一支，第五十八轮把还原规则整段删除（用户要「不要背景和边框」）。
- 选中态现行唯一表达：「引力放大」三件事 —— 字号 `1.08em`、字距 `0.02em`、单侧单层偏移像 `0.45px 0.45px 0 currentColor`。会话行作用在行内第二个 `span`，其余七类作用在直接子 `span`（容器只承担可继承的字距与偏移像，避免 1.08 连乘成 1.17）。
- 命令列表（`/` 与 `@`）的键盘高亮是 `[role='option'][aria-selected='true']`（`BUTTON.pc3rQa_item.pc3rQa_active`），第五十八轮补进钩子集合。此前它只靠 `--dsw-alias-interactive-bg-hover` 画底色，令牌被压死后完全看不见位置。
- 标签页选中官方本来就没有底色，只有文字色变化 + 26×2 下划线（`--dsw-alias-state-business-primary`）。
- 标签页悬停官方有底色（`.xeixwq_detailTab:hover`），被令牌压制连带关掉。
- 选中标签页的 `::after` 下划线在第五十五轮已还给官方，不再压制。
- 选择器受 `css.6` 约束：不能写 CSS-Modules 哈希类名，只能走 `[data-row-key^='session:']` 这类契约属性。
